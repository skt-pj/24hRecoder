# 0.7.93 Memoket STOP候補の音声による照合

0.7.92の手動振動判定をSTOP試験の主軸から除去。毎回03送信、5秒録音→停止候補1回→さらに10秒何も送信せず観測→BLE終了とし、候補を試す時刻と観測終了時刻をJSONに保存。

終了後にGemの録音が続いていれば本体ボタンで停止し、今回のGem録音を公式アプリまたは24hRecoderで安全に保存・書き出す。結果画面で該当のOgg Opusを選択。選択ファイルのOpus granule（Androidメタデータへフォールバック）、バイト数、ローカルCRC32を計測し、Gemファイル名の開始日時とテスト開始日時を照合。録音時間が停止候補までの約5秒に収まるか、観測終了の約15秒まで延びたかを比較する。重要：ローカルファイルCRC32はGem通知のCRC32とは区別する。音声取得はユーザー操作で行い、STOPテスト自体はACKを送らない。停止成功をBLE書込みや振動回数から決めず、短いファイルも停止「確定」ではなく「整合」と記録する（0x03のトグル／新ファイル生成の可能性があるため）。

今回の停止試験結果が有効になるには、Gemの録音ファイル名の時刻が試験開始と近く、別の録音でないことが必要。疑わしいファイルは停止判定を保留する。
